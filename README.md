# DaoHover

DaoHover implements a scalable, Event-Driven architecture with advanced Load-Balancing and Service-Discovery capabilities via a centralized Service Manager.

With DaoHover, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoHover.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
